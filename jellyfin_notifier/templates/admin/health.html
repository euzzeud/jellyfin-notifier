External monitoring

This endpoint is unauthenticated on purpose, so an external monitoring tool (Uptime Kuma, Grafana, a simple cron+curl check, …) can poll it directly without credentials. It returns HTTP 200 while healthy and HTTP 503 as soon as the poller looks stuck or the last mail failed to send.

Point Uptime Kuma's monitor type "HTTP(s) - Keyword" or "JSON Query" at this URL — no username/password needed.

Detailed metrics (Grafana / InfluxDB / Telegraf)

A second, richer endpoint for a full metrics pipeline: cumulative counters (mail sent/failed by type, HTTP requests by status class, admin login attempts, poll cycle duration) on top of the same live poller state as /health. Also unauthenticated, flat JSON, one field per line — a good fit for Telegraf's inputs.http plugin with data_format = "json" (no need for inputs.exec + curl).

Counters reset when the service restarts — as expected for this kind of metric, handle it in Grafana with non_negative_derivative() (InfluxQL) or derivative() (Flux) rather than reading the raw value as a rate.
Example Telegraf config 
[[inputs.http]]
  urls = ["{{ metrics_url }}"]
  name_override = "jellyfin_notifier"
  data_format = "json"
  interval = "60s"
